Appendix

Statistical Tables

The tables you are allowed in the exam. The Z-table below is computed live, so it is exact to four decimals.

A1 · Standard Normal (Z) Table

Each cell is the area to the LEFT of $z$, i.e. $P(Z \le z) = \Phi(z)$. Find your $z$ to one decimal down the left column, then the second decimal across the top. Example: $z = 1.96 \Rightarrow$ row 1.9, column 0.06 $\Rightarrow 0.9750$.

How to use it backwards For a right-tail area, use $P(Z > z) = 1 - \Phi(z)$. For a middle area between $-z$ and $z$, use $2\Phi(z) - 1$. To find the $z$ for a given tail (e.g. 2.5% in the right tail), hunt inside the table for the area $0.9750$ and read off $z = 1.96$.

A1b · Standard Normal — "Area from 0 to z" Table

This is the version your lecture slides use. Each cell gives $P(0 \le Z \le z)$ — the area between the centre line and $z$. The largest value in this table is about $0.5$, never close to 1. Example: $z = 1.56 \Rightarrow$ row 1.5, column 0.06 $\Rightarrow 0.4406$.

Converting between the two tables For positive $z$:  $\Phi(z) = 0.5 + \text{(this table)}$  and  $\text{this table} = \Phi(z) - 0.5$. That single line is why the slide solutions keep adding and subtracting 0.5 — they are working from this table, not the cumulative one.

A2 · Student's t Critical Values

Row = degrees of freedom. Column = area in one tail. For a two-tailed test at $\alpha = 0.05$, use the $t_{0.025}$ column.
