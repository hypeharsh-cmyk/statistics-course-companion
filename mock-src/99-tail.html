Statistical Tables

Standard normal · Student's t · Chi-square

Standard normal — area to the LEFT of z

Each cell is $\Phi(z) = P(Z \le z)$. Find the row for the first decimal, then the column for the second. For a right-tail area use $1 - \Phi(z)$.

Student's t — upper-tail critical values

The column heading is the area in ONE tail. For a two-sided 95% interval use the $t_{0.025}$ column; for a two-sided 99% interval use $t_{0.005}$.

Chi-square — critical values

The heading $\chi^2_{0.050}$ means the area to the RIGHT of that value is 0.050. For a two-tailed test at 5% you need the $\chi^2_{0.975}$ and $\chi^2_{0.025}$ columns.
