Critical values worth knowing without the table

$z_{0.05}=1.645$ · $z_{0.025}=1.96$ · $z_{0.01}=2.326$ · $z_{0.005}=2.576$. These four cover every $Z$ test you will meet at 10%, 5%, 2% and 1%, one- or two-tailed, and knowing them saves a lookup under time pressure.

A2 · Standard normal — area to the LEFT of z

Read the row for the first decimal of $z$ and the column for the second. The body of the table is $\Phi(z) = P(Z \le z)$. For an area to the right, subtract from 1.

A3 · Student's t — upper-tail critical values

The heading $t_{0.05}$ means the area to the right of that value is 0.05. For a two-tailed test at 5%, use the $t_{0.025}$ column.

A4 · Chi-square — critical values

The heading $\chi^2_{0.050}$ means the area to the right of that value is 0.050. For a two-tailed test at 5% you need both the $\chi^2_{0.975}$ and $\chi^2_{0.025}$ columns — the distribution is not symmetric, so the two must be looked up separately.
